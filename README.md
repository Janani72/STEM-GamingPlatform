# STEM Gaming Platform

## 📌 About the Project

STEM Gaming Platform is an educational gaming application designed to
make Science, Technology, Engineering and Mathematics (STEM) learning
more interactive and engaging through games.

## 🎯 Objectives

- Make STEM learning interactive and enjoyable
- Improve students' problem-solving skills
- Provide educational games based on STEM concepts
- Encourage learning through gamification

## ✨ Features

- Interactive STEM-based games
- Educational activities
- User-friendly interface
- Score and progress tracking
- Engaging learning experience

## 🛠️ Technologies Used

- Flutter
- Dart

## 📱 Project Type

Educational Mobile Application

## 🚀 How to Run

1. Clone this repository.
2. Open the project in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Connect an Android device or start an emulator.
5. Run the application using `flutter run`.
